항생제 사용 원칙

기출 기반 요약
  • MRSA (메티실린 내성 황색포도알균): Oxacillin, Cefoxitin resistant → 치료: Vancomycin

예방접종

기출 기반 요약
  • 폐암 환자 예방접종: 폐렴, 독감
  • 임신, AIDS(면역저하) 금기 접종 - 생백신: MMR, Varicella, Zoster, 일본뇌염, Rota 등
  • 사우디 아라비아 성지순례: 수막알균, 장티푸스
  • 35세 남자, HBV 치료중: HAV, Tdap, 폐렴구균 (대상포진 아님 - 대상포진은 50세 이상 or 면역저하)

폐렴구균 예방접종: PCV13 - 최소 8주간격 - PPV23

접종 시작 시점순서
65세 이전 PPV23 우선 접종1년 이상 뒤 PCV13, 8주 이상 뒤 PPV23 (PPV23 간격 5년 이상)
65세 이후 PPV23 우선 접종1년 이상 뒤 PCV13

HBsAg(+) 노출 시

기출 기반 요약
  • 미접종자: IG + V 3회
  • 접종자, 표면항체 형성: 조치 없음
  • 접종자, 표면항체 미형성: IG 1회 + V 3회 or IG 2회
  • 항체 형성 미상: Anti-HBs 실시, <10mIU/mL 이면 IG 1회 + V 1회

지역사회획득감염

기출 기반 요약
  • 수양성 설사, 세균성 장염 의심소견 없다면: 경구 수액, Loperamide로 대증치료
  • 염증성 설사 (발열, 혈변, 점액변): 대변 배양검사 시행
  • 동남아 여행 뒤, 우선적 사용 항생제: Fluoroquinolone(Ciprofloxacin), Azithromycin

의료관련감염 / 해외유입 감염병

C.difficile 감염 (Pseudomembranous colitis, PMC)

기출 기반 요약
  • 경도~중등도: Metronidazole PO / 중증: Vancomycin PO
  • 빠른 진단: 효소면역법 cytotoxin (ELISA) - toxin A/B 확인

뎅기열

기출 기반 요약
  • 후안와통증, 요통, LFT 상승, 가슴발진, 뼛속까지 애리는 통증, 위장관 출혈(피토하고 의식 잃음)

장티푸스 (Salmonella typhi)

기출 기반 요약
  • 분변-경구 감염, 발열 지속 + 상대적 서맥 + 변비 + 장미진(복부 희미한 발진)
  • 진단 - ￥혈액배양(초기): Blood(1주) > Urine(2주) > Stool(3주), 골수배양(민감도↑)
  • 치료: Ceftriaxone(PO), 경증 Azithromycin(PO), Ciprofloxacin(내성 많음), 필요시 + Dexa

가을철 열성질환

렙토스피라증 (Leptospira spp., 잠복기 1~2주)

기출 기반 요약
  • 농부, 발열, 근육통, 두통, 결막출혈, 객혈, 황달, 신부전
  • 치료: Doxycycline PO (or Azithromycin, Amoxicillin), 중증이면 Penicillin G IV

쯔쯔가무시병 (Orientia tsutsugamushi, 잠복기 1~2주)

기출 기반 요약
  • 발열, 피부발진, 가피, 림프절 종대
  • 치료: Doxycycline (or Chloramphenicol, Azithromycin)

신증후군 출혈열 (한탄바이러스, Seoul virus, 잠복기 2~4주)

기출 기반 요약
  • ￥ 여름 캠프 후 고열, 복통, 수일 후 발열은 호전되었으나 입이 마르고 저혈압 소견
시험 빈출 신증후군 출혈열 경과: 발열→저혈압(Dopamine, 이뇨제)→핍뇨(수분·전해질 균형, K 제한)→이뇨(수분·전해질 공급)→회복
치료: 대증치료, 신대체요법

가을철 3대 열성질환 감별

질환병원체/매개특징 소견1차 치료
렙토스피라증Leptospira, 농작업/오염수 노출결막출혈, 객혈, 황달, 신부전Doxycycline PO
쯔쯔가무시병Orientia tsutsugamushi, 진드기가피(eschar), 림프절 종대Doxycycline
신증후군 출혈열한탄/서울바이러스, 설치류 분변발열→저혈압→핍뇨→이뇨 4단계 경과대증치료, 신대체요법

그람 양성균 / 그람 음성균 감염

포도구균 - Toxic shock syndrome (TSS)

기출 기반 요약
  • S.aureus toxic exoproteins, 생리 중 탐폰 사용, 수술 후 감염, 피부 감염
  • 고열, 저혈압(쇼크), 전신 발진 → 탈락성 홍반(손·발), 다발성 장기손상
  • 진단: 임상적 진단 (혈액배양 음성 가능)
  • 치료: 탐폰 즉시 제거, 수액/혈압 유지, 항생제 1차: Vancomycin + Clindamycin

장구균 (Enterococcus)

기출 기반 요약
  • Uncomplicated UTI: Ampicillin (￥Imipenem도 가능)
  • Vancomycin은 내성 흔해서 사용하지 않음 (VRE 주의)

파상풍 (Tetanus)

기출 기반 요약
  • 3회 이상 접종: Clean 10년 이상, Dirty 5년 이상 경과 시 Td 1회
  • 3회 미만/미상: Clean - Td, Dirty - Td+TIG
  • 광견병: 면역력 없으면 Vaccine + RIG

단순연조직염 (Erysipelas)

기출 기반 요약
  • 경계가 명확한 홍반, 열감, 부종, 빠른 진행
  • 치료: Penicillin, macrolide, 1st Cepha (Cefazolin IV)

그람 음성균

기출 기반 요약
  • Pasteurella multocida: 고양이에 물림, 빨갛게 부으며 열감/통증, G(-) nonmotile coccobacillus
  • Vibrio vulnificus: 비브리오 패혈증 + 괴사성 연조직염(출혈성 수포, 괴사) - 하지 홍반, 물집 → 치료: Ceftriaxone + Doxycycline
  • Vibrio cholerae: 콜레라, 쌀뜨물 같은 설사
  • Vibrio parahaemolyticus: 비브리오 장염, 어패류(날것) 섭취

마이코박테리아 감염 (결핵)

기출 기반 요약
  • 감수성 결핵: 6개월 표준치료(2HREZ / 4HRE), 9HRE (Z 못쓰면)
  • 잠복결핵: INH 9개월 or RFP 4개월 or INH/RFP 3개월
  • 다제내성 결핵(INH+RFP 동시내성): ￥기존 약을 모두 바꾼다
  • INH 내성: REZ + Levofloxacin 6개월
  • 임산부: 기존 치료 유지, ￥피리독신(B6) 병행, 간기능 모니터링 필수
  • 소아(18세 이하): 9H 또는 3HR 권장
결핵치료 중 LFT 5배 이상 상승 시
모든 약 즉시 중단 → RHZ 순으로 투여하며 LFT 관찰 (5배 이하면 치료 지속)
간독성 없는 약제: Ethambutol, cycloserine, streptomycin
시험 빈출 결핵치료 중 영상 소견 악화되어도 증상 호전(역설적 반응)이면 치료 지속. 호전 없으면 H,R 신속내성검사
폐결핵 의심 시: 흉부 X선 → 객담 항산균 도말/배양(시간 오래걸림) → 결핵균 핵산증폭검사(빠른 확인)
결핵성 흉막염: 일측성 흉수, 흉수 ADA>40 이면 결핵 의심

폐외 결핵 - 신결핵

기출 기반 요약
  • 소변검사상 다수의 적혈구, 백혈구 관찰 but 소변배양검사 균(-), 요관협착, 수신증 → 신결핵

DNA/RNA 바이러스 감염 및 HIV

전염성 단핵구증 (EBV)

기출 기반 요약
  • 전신 증상(발열, 인후염) + 경부 림프절 종대 + ￥Heterophil Ab(+)
  • 치료: 대증치료, 항생제 불필요 (특히 페니실린계 - 발진 유발 위험)

독감(Influenza)

기출 기반 요약
  • 밀접접촉 후 예방적: Oseltamivir QD (노출 후 7~10일), 비접종자는 +백신 접종
  • 무증상 고위험군 예방적 복용 X (밀접접촉/고위험군/백신효과없음/미접종일 때만)
  • 치료: oseltamivir 75mg BID 5일

풍진

기출 기반 요약
  • 얼굴 발진, 구진성 발진, 뒷 목덜미 림프절 종대, 관절통

HIV 감염

기출 기반 요약
  • 선별검사: HIV 항체검사(ELISA) - 양성 or 미정 시 ELISA 한 번 더
  • 확진검사: Western Blot (PCR은 급성기/신생아 진단 보조적 사용)
  • 항체 형성 시기: 2주~3개월
  • 노출 후 예방: 72시간 이내 항레트로바이러스제(Truvada+DTG/RAL) + ELISA, 28일 유지 후 4주·12주 추적
  • AIDS 환자 - 생백신 금지 (MMR, Varicella 등)
  • CD4+ 40, 폐렴 증상 → 가장 가능성 높은 원인: Pneumocystis jirovecii pneumonia (PJP)
  • 감염경로: 혈액, 정액, 질액, 모유

진균 / 원충 / 기생충 감염

구강 칸디다증

기출 기반 요약
  • 당뇨, 스테로이드 흡입제 사용자 > 치료: Nystatin 가글

말라리아

기출 기반 요약
  • 주기성 발열(오한-발열-발한 반복), 빈혈, 비장비대, 두통, 근육통, 황달
  • 확진검사: 말초혈액도말
  • 국내: Plasmodium vivax(삼일열) / 미얀마-태국 접경: P. falciparum(열대열)
  • 치료: Chloroquine + Primaquine (G6PD 결핍 확인 후 Primaquine)
  • 신경계 증상(GTC 발작) 동반 → 중증 말라리아 → IV Artesunate 즉시 투여
  • 예방약: Atovaquone-Proguanil(내성지역) / Mefloquine(내성지역, 임산부 가능)
