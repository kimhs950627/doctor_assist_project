빈혈 일반

기출 기반 요약
  • 65세 이상에서 (철결핍) 빈혈이 있을 경우, 위·대장내시경을 통한 출혈 원인 감별이 필수

철결핍 및 기타 저증식성 빈혈

기출 기반 요약
  • 철결핍 빈혈 (IDA)
    • Hb, Hct 감소 (빈혈 소견), MCV 감소 (<80fL, 소적혈구), MCH, MCHC 감소 (저색소성)
    • 혈청 페리틴 감소 (<15 ng/mL, 철 저장량 부족), 혈청 철(Fe) 감소, 총 철결합능(TIBC) 증가 (정상:250-400)
    • 말초혈액도말: 소적혈구(hypochromic, microcytic), 타겟 셀 가능
  • 만성질환빈혈(ACD)
    • 페리틴 정상or증가 (염증성 단백질), 총 철결합능(TIBC) 정상, MCV 정상or약간 감소

거대적혈모구 빈혈

기출 기반 요약

￥ MCV 증가, B12 정상, folate 정상.. → 대적혈구 빈혈

  • MCV 증가 (>100 fL, 거대적혈구), 망상적혈구 ↓ (비효율적 조혈), Hypersegmented neutrophils (과분엽 호중구), 혈청 LDH ↑, 간접 빌리루빈 ↑ (용혈 동반)
  • 비타민 B12(cobalamin) 결핍: 위 절제술, 위축성 위염 (Intrinsic factor 부족), 회장 말단 질환 (크론병, 회장 절제술), 장내 세균 과증식, Vegan
    • 증상: 혀가 붉고 매끈, 통증호소 / 신경학적 증상: 사지 저림, 감각 이상
    • 치료: 비타민 B12 매월 근육주사
    • 검사: Serum MMA (methylmalonate) - ￥민감도 가장 높은 검사 (cobalamin 아님, MMA가 답)
      B12 정상 200-900 pg/mL, 200-399 pg/mL 이면서 증상있으면 MMA 측정해서 결핍 확인
  • 엽산(Folate) 결핍: 만성 알코올 중독, 임신 (필요량 증가), 영양 결핍, 장 질환(셀리악병), 항대사제 사용 (MTX(류마티스관절염), TMP, Phenytoin 등)
    • 치료: folate 경구 치료

용혈성 빈혈

기출 기반 요약

공통 특징: 망상적혈구(reticulocyte) 증가, LDH 증가, 간접 빌리루빈 증가, Haptoglobin 감소

￥ 빈혈 & 황달, 간, 비장비대. 더 필요한 검사? → 망상적혈구(reticulocyte) 측정
￥ reticulocyte 증가, total bilirubin 4.5, 더 필요한 검사? → Haptoglobin: 용혈 표지자

  • 유전성 구상적혈구증 (HS)
    • 비장비대, 담석(색소성 담석) 위험 증가 (￥담석증 과거력)
    • 구상적혈구(spherocyte), 삼투압 취약성 검사(Osmotic fragility test) 양성
    • 중증: 비장절제술(Splenectomy) (수술 전 폐렴구균, 수막구균, 인플루엔자 백신 필수)
    • 경증: 대증 치료, 엽산 보충 (적혈구 생성 보조)
  • 자가면역 용혈성 빈혈(AIHA)
    • 원인: 특발성, 자가면역 질환(SLE), 림프종, CLL, 약물 유발(Penicillin, Methyldopa 등)
    • 진단: Direct Coombs test 양성
    • 1차 치료: 고용량 스테로이드 (Prednisone 1mg/kg/day) / 2차: 리툭시맙, 비장절제술
    • 응급 상황(중증 용혈, Hb 급감): 수혈(가능하면 자가수혈)
  • 발작성 야간혈색소뇨증(PNH)
    • 적혈구가 보체에 의해 파괴됨. 야간 용혈 & 아침 첫 소변 적갈색
    • 정맥 혈전증(Budd-Chiari syndrome), 범혈구 감소증 동반 가능. Hemosiderinuria
    • 진단: Flow cytometry: CD55(-), CD59(-)
    • 치료: 보체 억제제 (Eculizumab, Ravulizumab), 필요 시 스테로이드, 조혈모세포이식
RPI (Reticulocyte production index) 의미
용혈성 빈혈(HS, AIHA, PNH) → RPI > 2.5 골수 보상 정상
재생불량성 빈혈(Aplastic anemia) → RPI < 2.0 골수 보상 부족
철결핍성 빈혈(IDA), 만성질환 빈혈(ACD) → RPI 낮음 조혈 부족

재생불량 빈혈 (Aplastic anemia)

기출 기반 요약
  • 골수 기능 저하로 인해 Pancytopenia, 망상적혈구 감소
  • 원인: 특발성(가장 흔함), 약물 유발(항암제, NSAIDs, Chloramphenicol, Phenytoin), 바이러스 감염(EBV, CMV, B19), 독성 물질(벤젠)
  • 임상 증상: 빈혈, 감염 (특히 호중구 감소), 출혈
  • 진단: 골수생검 (Bone marrow biopsy) → 조혈세포 감소, 지방 침착 증가
  • 치료: 경증/어린이/젊은성인 - 관찰 + 조혈촉진제(EPO, G-CSF)
    중증 - 조혈모세포이식 (1st line), 면역억제 치료 (Cyclosporine + ATG, 2nd line)

적혈구 증가증 / 골수증식성 질환

기출 기반 요약
  • 상대적 적혈구 증가증: 흡연, 탈수, 남성호르몬(Androgen) 사용, 스테로이드
    ￥ Hb18, PLT 14만, 치료?: 금연 (not 사혈)
  • 이차성 적혈구 증가증: 만성 저산소증(COPD, 고산병), 신장 질환(EPO 증가)
  • 진성 적혈구 증가증 (PV): JAK2 돌연변이 동반, WBC/혈소판 증가
    ￥ Hb19, Plt 54만, 입술 검고, 비장비대, 사우나가면 소양감 → PV → Phlebotomy(정맥절개술, 사혈)
    ￥ 진성 적혈구 증가증 의심할 수 있는 소견?: 비장비대, 혈소판 증가증 (>45만/uL)
  • 본태성 혈소판증가증 (Essential thrombocythemia): 혈전, 출혈 위험, 적혈구통 / 치료: Aspirin

형질세포질환

기출 기반 요약
  • 다발골수종(Multiple Myeloma, MM)
    • CRAB: C (Calcium ↑ 고칼슘혈증) / R (Renal impairment 신부전) / A (Anemia 빈혈) / B (Bone lesion 요통, 병적 골절), A/G ratio 역전
    • 혈청 & 소변 단백 전기영동 → M-spike 확인
    • 면역고정검사(IFE) → M 단백의 종류 확인
    • 골수검사 → 형질세포(Plasma cell) ≥ 10% 시 진단
    • 치료: 항암유도요법 후 자가조혈모세포이식(ASCT) / ASCT 불가 시: Bortezomib+Lenalidomide+Dexamethasone
      골 보호, 신장 보호, 고칼슘혈증 치료 병행

혈소판 및 혈관벽 질환

기출 기반 요약
  • ITP (Immune thrombocytopenia): 면역성 혈소판 파괴 → 자반, 멍, 점막출혈
    치료: PLT < 30,000는 스테로이드, 재발 시 비장절제술 / PLT 3만 이상이면 추적관찰
  • TTP (Thrombotic thrombocytopenic purpura): FATRN (발열, 용혈, 혈소판 감소, 신경, 신장)
    치료: 혈장교환술
  • HUS (Hemolytic uremic syndrome): O157 E. coli 감염 후 설사 + 신부전
    치료: 대증치료(항생제 금기), ￥수혈 (Hb 6, 5세, 설사, 발열, 소변량 줄음, helmet cell, burr cell)
  • HSP (Henoch-Schonlein purpura): 혈관염으로 인해 신장에 IgA 침착
    자반 + 복통 + 관절통 + 신장침범소견(혈뇨/단백뇨) → 소변검사 반복, 대증치료

부종양증후군

기출 기반 요약
  • Spinal cord compression: NSCLC 환자, 가슴 이하 감각 마비, 하지 운동마비, 소변 못보는 증세 → Steroid 투여
  • SVC syndrome: 경정맥 확장, 앞 흉벽 곁 정맥 수 증가, 청색증, 부종, 안구 돌출 → 흉부 CT 확인
