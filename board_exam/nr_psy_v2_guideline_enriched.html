[신경과] 1. 신경학적 검진·어지럼

기출 기반 요약
  • 왼쪽 편측무시: 오른쪽 두정엽 병변 의심.
  • 눈외근 신경 배분: L6SO4.
  • 말은 이해하나 말을 못함: 운동실어증(브로카영역 손상).
  • 대광반사: 빛 입력 CN II, 동공 수축 CN III.
  • 근력: 수축 없음 0, 약간 수축 1, 중력 제거 시 움직임 2, 중력 대항 3, 저항 대항 4, 정상 5.

BPPV자세변화 시, 1분 내 소실, 고개 돌리면 악화Dix-Hallpike, Epley
메니에르spinning type, 2시간, 식은땀, 이충만감, 난청, 바람소리저염식(이뇨제)
전정신경염1주 전 감기 후 급성 어지럼·구토·자발안진·보행 편위3일 내 steroid, 심한 현기증 Diazepam, 3일 후 전정재활
척추기저부동맥부전DM/HTN + 어지럼 + 복시 → central 의심뇌혈관 평가
TIA뇌허혈 증상 24시간 내 회복즉시 항혈소판: 1차 Aspirin, 필요 시 Clopidogrel
추가 포인트: 딸국질+시야결손은 중추성 감별 위해 Brain MRI. 기침·재채기 시 두통은 뇌압상승 의심.

[신경과] 5. 이상운동·인지장애

질환원문 특징치료/주의
본태떨림의도 시 떨림, 음주로 완화, 가족력, 소뇌기능 정상Propranolol, primidone
파킨슨병안정시 떨림, 경축, 운동완만, 보행이상, 자세불안정Levodopa, pramipexole/ropinirole. 도파민작용제: 하지부종·주간졸림·환각·충동장애. Levodopa 5년 이상: 이상운동증
약물유발 파킨슨증고령, Levosulpiride, Metoclopramide, Fluoxetine 등약물 검토
하지불안증후군밤에 다리 불편·움직임 충동, 움직이면 완화카페인·알코올·니코틴 제한, ferritin ≤50이면 철분, 유발약물 중단/교체. 1차 pramipexole/ropinirole, 말초신경병증 동반 시 gabapentin/pregabalin. 수면장애 clonazepam, 중증 tramadol/oxycodone
정상압수두증보행장애(종종걸음), 배뇨장애, 인지저하, MRI 뇌실확장(위축X)대량 LP, 뇌압측정, VP shunt
FTD행동·언어 장애가 초기 주 증상, 초기 기억력 감소는 두드러지지 않음특이치료 없음, 증상완화·가족교육
DLB인지저하+파킨슨증, 시각적 환각, 인지 변동성, REM 수면 행동장애Donepezil, Rivastigmine 1차
일차진료 가이드라인 보강 — 하지불안증후군 (#46)
  • 고령 불면의 약 30%가 RLS 원인 → 고령 수면장애에서 반드시 체크. 이차성 원인: 철분결핍, 신부전, 말초신경병증, 임신, 약물(도파민 차단제, 항히스타민제, AChEI).
  • 진단 5기준(모두 충족): 하지 불쾌감각·움직임 충동 / 움직이면 완화 / 휴식 시 발생·악화 / 저녁·밤에 심함 / 다른 질환으로 설명 안 됨. 검사: CBC, Ferritin, TIBC, reticulocyte.
  • 치료: Ropinirole 0.25→0.5mg 시작, 주당 0.5mg씩 최대 4mg(취침 1~3시간 전, G258 급여) / Pramipexole 0.125→0.25→0.5mg 4~7일마다 증량(취침 2~3시간 전). 증상 조절 후 1~2개월 뒤 서서히 tapering.
  • Pregabalin이 dopamine agonist와 동등 이상 효과 + '증강현상(augmentation)' 부작용 없어 1차로 제시되기도 함 (2020). 신경병증·통증 동반 시 pregabalin/gabapentin/amitriptyline/nortriptyline.
  • 수면제로 효과 있는 것: Clonazepam 0.25~0.5mg, Melatonin 서방정. 철분: ferritin 50 이하 시 보충. 매우 심한 경우 opioid HS 고려.

[정신과] 9. 강박·신체증상·해리·식사장애

  • 우울 vs 치매 감별: 우울 = 급격 발병·단기, 호소가 객관 검사보다 심함, '모른다' 대답, 굴곡 심함, 우울정동 선행 / 치매 = 서서히 장기간, 병식 부족, 근사치 대답, 단기기억부터 손상, 인지저하 선행. 60세 이전 우울 없다가 신발 우울 호소 시 기저 치매 진행 확인. SGDS 병행.
일차진료 가이드라인 보강 — 치매 치료제 (#53)
  • 시기별: 초기(기억장애) AChEI / 중기-중후기(BPSD) AChEI+Memantine 병용·BPSD 약물 / 말기 보존적·일상생활 중심. 효과: 완치 아닌 진행 지연, 3명 중 1명은 호전 없음.
  • AChEI 공통: 부작용 10~20% 용량비례(구역·구토·설사·식욕감소·체중감소·어지러움·근경련·수면장애·요실금·천식 악화). 저용량 시작 천천히 증량. 신중투여: 동부전·전도장애(서맥·부정맥), 소화성궤양·NSAID 병용, 천식·COPD, 파킨슨증후군.
  • Donepezil: 반감기 70h QD. 5mg 시작 최소 4~6주 후 10mg(고령은 2.5mg 1~2주 선행). SSRI는 농도↑, 항경련제는 농도↓. 23mg은 MMSE ≤20 중등도 이상·10mg 최소 3개월 후. 패취 87.5→175mg(4~6주 간격), 경구 부작용 시 선호. 악몽·불면 시 아침 복용.
  • Rivastigmine: AChE+BuChE 억제 → 파킨슨병치매 급여 유일, DLB·후기 알츠하이머 도움. 1.5mg bid → 2~4주 간격 최대 6mg bid(위장관 부작용 심함). 패취 QD 5→10→15cm², 경구<6mg/d면 5cm², ≥6mg/d면 10cm²로 전환. Donepezil은 반감기 길어 중단 4~5일 후 시작. 부착: 윗가슴·등·위팔(복부·허벅지 흡수 낮음 → 천천히 증량에 이용 가능).
  • Galantamine: AChE 억제+니코틴수용체 조절, 서맥·수면 부작용 상대적으로 적음. 8mg → 4주(최소 2주) 간격 16 → 최대 24mg. CYP2D6/3A4 저해제 병용 시 콜린성 부작용↑.
  • Memantine: NMDA 길항제, 반감기 60~80h, 위장관·불면 부작용 없음. 5mg → 주 5mg씩 증량 → 20mg(10mg bid). BPSD(공격성·초조·야간행동) 감소 — APS 전에 memantine 우선 고려. 뇌전증·NMDA길항제 병용·요 pH 상승 상황 주의.
  • 급여기준(고시 2025-73): AChEI MMSE ≤26·CDR 1~3·GDS 3~7(Donepezil 캡슐/패취; rivastigmine/galantamine MMSE 10~26·CDR 1~2·GDS 3~5; 패취는 ≤26), Donepezil 23mg·Memantine MMSE ≤20·CDR 2~3·GDS 4~7. F01 혈관성치매는 donepezil 급여 인정 X. 기준 초과해도 지속투여 인정. 6~12개월마다 재평가(중증 MMSE<10·CDR3/GDS6~7은 6~36개월, 장기요양 1등급은 유효기간까지). 처방 시 JT007 특정내역에 MMSE/CDR/GDS 결과·검사일 기재.
  • 병용: AChEI+Memantine은 각 기준 부합 시 가능(MMSE ≤20). Ginkgo 병용은 1종 전액본인부담. 뇌대사개선제 1종만 급여. 치매 산정특례: 중증(MMSE ≤18·CDR ≥2), 1군(FTD/DLB/early onset) 무제한, 2군 60일.
  • 추적: 약물 조절 천천히, EKG·LFT f/u, 식사량·체중 변화 확인, 만성질환(HTN/DM/DL) 관리가 치매 경과에 도움. 알코올 의존·문제음주 인지장애 환자: 고용량 Thiamine 100~300mg/day 6개월 이상 장기 처방 권유.
일차진료 가이드라인 보강 — BPSD (#54)
  • 치매 환자 ~90%가 1개 이상 BPSD. 초기에는 mood 증상, 중기 이후 behavior 증상. 약물 적응증: 비약물 치료(환경 정비·활동·음악·행동치료) 실패 또는 자타해 위험. 효과평가 4주(천천히 증량 시 6주), 3개월마다 중단 검토. 타겟 증상을 정해 관리, 소량 시작 천천히 증량, 중단 가능하면 중단.
  • 치매치료제 먼저: AChEI 증량 또는 시작, Memantine(AChEI 병용 시 BPSD 추가 호전) — 일차의료에서 APS 전 우선 고려.
  • 우울 증상: 노인은 약전 초회·최대의 절반. 1차 Sertraline 또는 Escitalopram(상호작용 최소, 20mg↑ QT). 시작/목표 용량: escitalopram 5→10~20, sertraline 25→50~100, fluoxetine 10→20~30(상호작용 많아 노인 신중), paroxetine(항콜린·인지저하로 비선호), mirtazapine 7.5→15(sedation 주의), bupropion(경련·두부외상 금기), TCA 중 nortriptyline 선호. 저용량 시작 1~2주마다 증량, 1년 이상 필요 시 연 1회 감량 시도.
  • 항정신병약(망상·환각·공격성·초조·수면장애): FDA 2005 — 비정형 APS 사망률 1.6~1.7배, risperidone/olanzapine 뇌졸중 위험 → 먼저 환경 개선·memantine·SSRI. 용량: quetiapine 6.25~12.5→25~150(EPS 고려 우선, 저용량 수면·고용량 행동증상), risperidone 0.25~0.5→0.5~2(호전 즉시 감량, TD 위험), haloperidol 0.25~0.5→0.5~2, olanzapine 1.25~2.5→5~10(체중증가, 우울 동반 agitation), aripiprazole 2.5→2.5~5(QT 영향 적음). 12주 넘기지 않도록, 효과 있어도 4~6개월 내 감량·중단 목표. Quetiapine >100mg, risperidone >2mg 등 고용량 필요하면 정신과 의뢰.
  • DLB는 neuroleptic sensitivity — 항정신병약 치명적 부작용, 전문의 의뢰. EPS가 용량 대비 과하면 DLB 의심.
  • QT: APS 투여 전후 EKG, 연 1회 주기적 검사. QTc >500ms 또는 기저 대비 30~60ms 증가 → aripiprazole 등으로 교체. Clozapine은 ANC 위험으로 사용 X.
  • Akathisia 대처: 중단 + propranolol 10~40mg tid, 불응 시 clonazepam 또는 quetiapine 교체. 급성 근긴장증: benztropine 등 항콜린제, 불편 해소에 diazepam 5~10mg slow IV(호흡억제 고려 lorazepam IM/IV 가능).
  • 항경련제(공격성 2차): valproic acid 100→100~1,000, carbamazepine 250→500~600(골수억제·SJS·신손상, 혈액검사), gabapentin 300→300~1,200 — 이 정도면 의뢰.
  • BZD(불안·초조·수면장애): 낙상·혼돈·과진정·paradoxical response(초조·탈억제, 특히 밤) 주의. 단반감기·lorazepam 선호(간 의존 적고 활성대사물 없음). 소량 단기.
시험 빈출 + 가이드라인 총정리
  • 불면증 진단 = 주 3회·3개월. 1차 치료는 약물이 아니라 CBT-I. 수면제는 4주 이하 원칙, tapering은 4~16주 10~25%씩.
  • Zolpidem = 28일 제한·음주 금지·우울증 피함 / Triazolam = 반동불면·의존 최고 / 유지장애는 비의존성(Doxepin, Trazodone) 우선.
  • RLS: ferritin ≤50 철분, pregabalin ≧ dopamine agonist(증강현상 없음). RBD 1차 melatonin·clonazepam, 항우울제 악화.
  • 치매 급여: AChEI MMSE ≤26 / memantine·donepezil 23mg MMSE ≤20, 6~12개월 재평가, JT007 기재. F01 혈관성치매는 donepezil 급여 X.
  • BPSD: 비약물 → AChEI·memantine → SSRI(sertraline/escitalopram) → APS(사망률·뇌졸중 경고, 12주 이내). DLB에 항정신병약 금기 수준.
  • 60세 전 우울 없던 신발 노인 우울 = 기저 치매 확인. 기억회상 0점 = MCI/알츠하이머 강력 의심.
