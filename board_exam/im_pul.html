호흡기내과

가정의학과 전문의 시험 대비 요약

원본: 2권 심혈관,호흡기,류마티스.docx (호흡기 파트 전문)

폐기능검사

기출 기반 요약
  • 말초 소기도 병변 진단할 때 도움: FEF 25-75%
  • FEV₁/FVC < 70% → 폐쇄성(obstructive): COPD, 천식 등
  • PFT에서 폐쇄성 패턴(FEV₁/FVC < 70%)이 보일 때: 기관지 확장제 반응 검사(BDR) 시행 → 천식 or COPD 감별
    • 양성(가역성 O, ￥FEV₁ ≥ 12%(base에서 상승률) & 200mL 증가) → 천식
    • 음성(가역성 X, 변화 없음) → COPD
  • PFT 정상이지만 천식 의심되거나, 천식 확진이 필요할 때: 메타콜린 유발 검사(기관지 수축 유발 검사) 시행 → 기관지 과민성(BHR) 평가
    • 양성(PC20 ≤ 4 mg/mL) → 천식 가능성 높음
    • 음성(PC20 > 16 mg/mL) → 천식 가능성 낮음
  • FVC 감소, FEV₁/FVC 정상 또는 증가 → 제한성(restrictive): 미만성간질성폐렴, ILD, 폐결핵 후유증 등
  • TLC 감소 → 제한성 질환 강력 시사
  • DLCO 감소 → 간질성 폐질환, 폐혈관질환 가능성

호산구성 기관지염

기출 기반 요약
  • 천식과 유사하지만 기관지 과민성(BHR)이 없음, 만성 기침(기침만 있고 호흡곤란 없음)
  • 진단: PFT 정상(FEV₁/FVC > 70%), 메타콜린 유발 검사 음성(천식과 차이점), 객담 호산구 증가(≥2~3%) 확인
  • 치료: 흡입 스테로이드(ICS) → 효과적

급성 기관지염

기출 기반 요약
  • 야외활동 후 발생, Parainfluenza virus, 감염 후 기침, X-ray 정상, 객혈도 보일 수 있음
시험 빈출 흉수 ADA 증가 → 결핵성 흉막염

만성 기침 주요 감별진단

원문에 표/그림으로 제시된 만성기침(>8주) 감별진단 알고리즘: UACS(상기도기침증후군), GERD, 기침형천식(CVA), 호산구성 기관지염, ACEi/DPP-4i 약물유발, 흡연 등이 주요 원인이며 CXR 우선 시행 후 순차 감별함. 도식 원본은 docx 참조 필요.

천식

천식 치료 단계별 전략

step치료 전략대상 환자
step 1 (간헐적 천식)필요 시 저용량 ICS-formoterol 사용(PRN)증상 경미하고 간헐적으로 발생
step 2 (경증 지속성 천식)매일 저용량 ICS 유지 or 필요시 저용량 ICS-formoterol주 2회 이상 증상 발생, 야간 증상 존재
step 3 (중등도 지속성 천식)저용량 ICS + LABA (유지 치료)일주일에 3회 이상 증상 발생
step 4 (중증 지속성 천식)중등도~고용량 ICS + LABA증상 지속적, 중증 악화 위험 높음
step 5 (최중증 천식)고용량 ICS + LABA + 생물학적 제제 추가(Anti-IgE, Anti-IL5)기존 치료에도 조절되지 않는 중증 천식

1) 염증 조절제 (천식의 근본 치료)

약물군예시기능
흡입 스테로이드(ICS)Budesonide, Fluticasone, Beclometasone가장 효과적인 천식 조절제(항염증 작용)
류코트리엔 조절제(LTRA)Montelukast, Zafirlukast운동유발성 천식, 알레르기성 천식에 효과적
생물학적 제제(Biologics)Omalizumab(Anti-IgE), Mepolizumab(Anti-IL5)중증 호산구성 천식에 사용

2) 기관지 확장제 (증상 완화)

약물군예시기능
속효성 β2-작용제(SABA)Salbutamol(Ventolin)급성 증상 완화(응급 시 사용)
지속성 β2-작용제(LABA)Formoterol, SalmeterolICS와 병용하여 장기 조절제 역할
항콜린제(LAMA, 흡입형 무스카린 길항제)Tiotropium(Spiriva)LABA에 반응이 부족한 중증 천식에 추가

3) 천식 급성악화

증상 심한 정도치료방법
경증~중등도 악화Salbutamol(SABA) 흡입 + 경구 스테로이드(PO Prednisolone 40~50mg)
중증 악화(호흡곤란 심함, 말하기 어려움, SpO2<90%)네블라이저 SABA + Ipratropium(항콜린제) + IV 스테로이드
삽관 필요(Life-threatening)고유량 산소, IV Magnesium sulfate, 기계환기 고려
기출 기반 요약
  • 임신 중 천식: SABA(흡입 salbutamol, 흡입 terbutaline) 먼저 사용(즉각 기관지 확장) → 유지치료 ICS
  • 천식 치료 효과 판정: FEV₁ ≥ 80% & PEFR ≥ 80% → 치료 양호
  • 알레르기 천식 환자가 항원 노출이 예상될 때 예방적 약물: Cromolyn Sodium(비만세포 안정화제)
  • 테오필린 부작용: 오심, 구토, 식욕감소, 두통, 불면증, 중추신경계 흥분, 심한 경우 부정맥, 발작(경련) 발생 가능 → 혈중 테오필린 농도 검사, 테오필린 용량조절 또는 중단(테오필린 지금은 거의 안쓴다.. 보조치료)
  • 테오필린 농도가 정상보다 낮게 유지되는 상황: 흡연, phenytoin, rifampin, carbamazepine, phenobarbital

아스피린 유발 천식 (AERD)

기출 기반 요약
  • NSAIDs 복용 후 천식 악화, 만성 부비동염, 비용종
  • NSAID/아스피린이 COX-1을 억제하여 류코트리엔 증가 → 기관지 수축 심화
  • 진단은 병력 청취가 가장 중요, 필요 시 아스피린 유발 검사 시행 가능
  • 치료는 NSAID 회피 + ICS/LABA + 류코트리엔 조절제(Montelukast)가 기본
  • 진통제 필요시: AAP, COX-2 억제제(celecoxib)

과민성 폐렴 / 호산구 폐침윤

과민성 폐렴 (Hypersensitivity pneumonitis)

기출 기반 요약
  • 유기물(￥버섯, 곰팡이, 새 깃털 등) 반복 노출 후 발생
  • HRCT: 모자이크 패턴, 중심엽 침윤, BAL: 림프구 증가(>40%)
  • 폐 기능 검사: 제한성 폐질환(TLC 감소)
  • 치료: ￥원인 회피 + 필요 시 스테로이드

호산구 폐렴 (EP)

기출 기반 요약
  • 말초 혈액 & 폐포 내 호산구 증가
  • HRCT: GGO 및 consolidation. 말초부위에 발생, 양측성으로 발생(일반 세균성 폐렴은 특정 lobe나 segment에 국한되어 나타남)
기출 기반 요약
  • BAL: 호산구 증가(>25%)
  • 폐결절 이동성 패턴(￥몇개월 전 결절이 사라지고 다른 부위에 생김)
  • 치료: 경과 관찰, 증상 있으면 스테로이드

폐흡충증에 의한 eosinophilic lung disease

기출 기반 요약
  • 민물 회 즐겨 먹음. cough, hemoptysis, dyspnea, CXR 상 불규칙한 폐침윤, 흉수에서 호산구 증가
  • 확진 검사: 대변검사

회충에 의한 eosinophilic lung disease

기출 기반 요약
  • Ascaris lumbricoides, Paragonimus westermani

환경성(직업성) 폐질환

석면폐증 (Asbestosis)

기출 기반 요약
  • 조선소, 단열재 작업(보일러공), 건설, 철도..
  • CXR, CT 소견: 하엽 침범, 흉막반(pleural plaques), 흉막비후, 간질성 폐섬유화

규폐증 (Silicosis)

기출 기반 요약
  • 광산, 유리, 도자기 공장, 주물공장, 터널공사, 대리석 가공
  • CXR, CT 소견: 폐상부~중부의 small, round nodule, 규폐 결절, 계란껍질 석회화

면분증 (Byssinosis)

기출 기반 요약
  • 면직물, 방직, 섬유 공장
  • CXR, CT 소견: 비특이적 폐섬유화, 주로 기도 과민성 증가(천식 유사 증상), Monday chest tightness

폐렴

1) 감염 경로에 따른 분류

기출 기반 요약
  • 지역사회획득폐렴(CAP), 병원획득폐렴(HAP), 인공호흡기연관폐렴(VAP), 흡인성폐렴(Aspiration pneumonia)으로 분류

2) 원인균에 따른 분류

시험 빈출 ￥독감 후 폐렴 원인균: S. aureus(급격한 진행, 폐 괴사, 공동 형성 가능)

3) 주요 폐렴의 임상적 특징

4) 입원 치료 기준 - 폐렴 중증 지표 (CURB-65)

시험 빈출 ￥지역사회 폐렴환자에서 심하다고 판단할 수 있는 소견: 호흡수(RR) ≥ 30회

기관지 확장증 / 폐농양

폐농양 (Lung abscess)

기출 기반 요약
  • 기침, 전신쇠약, 발열, 오한, 몸살
  • 혐기성균 포함 항생제 치료(Ampicillin/sulbactam, Clindamycin, Carbapenem), 경구 전환 가능 시 Augmentin or Clindamycin PO 사용
  • ￥ceftriaxone + clindamycin
  • 치료 기간 최소 4~6주, 6cm 이상이거나 치료 반응 없을 시 배액 고려

기관지확장증 (Bronchiectasis)

기출 기반 요약
  • 백일해 hx, 만성 기침과 가래, 반복 폐렴 입원
  • ￥흉부 CT에서 기관지 확장(signet ring sign) 확인 → 확진
  • 치료 핵심: 객담 배출 + 감염 예방 + 급성기엔 항생제 치료(￥levofloxacin)
  • Pseudomonas(녹농균) 감염이 흔하므로, 항녹농균 항생제 필요 시 사용
  • 급성기 치료 후 ￥호흡재활치료

COPD

기출 기반 요약
  • COPD: 만성 기침, 가래, 호흡곤란, 가장 중요한 원인은 흡연
  • 진단: 폐기능검사(FEV1/FVC < 70%)
  • 치료: 금연 + 기관지 확장제(LAMA/LABA; indacaterol+tiotropium)
  • 급성 악화 시: 기관지 확장제 증량 + 스테로이드 + 필요 시 항생제
COPD의 자연경과 변화시킬 수 있는 유일한 3가지 치료: 금연, 산소요법, 폐용적 감소술
￥산소 치료: PaO₂ ≤ 55 mmHg(SpO₂ ≤ 88%)일 때 저유량 산소 공급 → 생존률 향상치료!!
기출 기반 요약
  • 급성 고탄산혈증 호흡부전: 비침습적 기계환기(NIV, BiPAP)가 1차 치료
  • 폐절제술 시행여부 판단: FEV1 예측치
  • 기관지 확장효과 없지만 삶의 질 개선시키는 약: PDE-4 억제제(보조치료개념, 정신과병력 주의)
COPD 안정기 치료: GOLD 그룹(A/B/E)에 따라 기관지확장제(LAMA 또는 LAMA+LABA) 단계적 적용, 급성악화 반복 시 ICS 추가 고려. 세부 알고리즘은 GOLD 최신 가이드라인 확인 필요.

흉수

Light's criteria

기출 기반 요약
  • pleural/serum protein > 0.5
  • pleural/serum LDH > 0.6
  • pleural fluid LDH가 serum LDH upper limit의 2/3 이상
Light's criteria 중 1개 이상 만족 시 삼출액(exudate)으로 판정, 모두 미충족 시 누출액(transudate)으로 판정함.

흉관 삽입 적응증

기출 기반 요약
  • loculated pleural fluid
  • pleural fluid pH ≤ 7.2
  • pleural fluid glucose < 3.3mmol/L (60mg/dL)
  • 그람염색 양성, 흉막액 배양검사 양성
  • 흉강 내 육안상 pus 발견(empyema)

기흉

기출 기반 요약
  • <50% - 바늘 흉강천자 / >50% - 흉관삽입술
  • 재발성 기흉 - VATS(Video-assisted thoracoscopic surgery)
  • 기흉을 가장 잘 볼 수 있는 X-ray 사진: 최대 호기 chest PA
