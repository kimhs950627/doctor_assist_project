# Feature 13 — 직원 공지 자동 생성

## 목적
원장이 짧은 메모를 입력하면 직원에게 전달할 공식적인 공지문을 자동 생성한다.

## 사용 방법
1. 대시보드 `직원 공지` 탭 열기
2. 핵심 내용 메모 입력 (예: `내일부터 점심 1시간 30분으로 연장`)
3. 공지 유형 선택 (진료 변경 / 행정 / 교육 / 긴급)
4. `공지 생성` 클릭
5. 검토 후 `발송` → 카카오톡/SMS 자동 발송 or 출력

## Grounding 정책 (→ grounding_sources.md 참조)

| 공지 유형 | Grounding 소스 | 적용 조건 |
|---|---|---|
| 진료 절차 변경 공지 | 보험 고시 크롤링 | 수가·급여 기준 관련 언급 시 |
| 감염 예방 지침 공지 | PubMed E-utilities | CDC/KCDC 지침 인용 시 |
| 약품 보관·취급 공지 | 의약품안전나라 크롤링 | 특정 약물 취급 기준 언급 시 |
| 일반 행정 공지 | 해당 없음 | — |
