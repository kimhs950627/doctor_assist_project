# Feature 05 — Google Calendar 연동

## 목적
진료 일정, 야간 자동화 실행 결과, 논문 큐레이션 요약을 Google Calendar에 자동 등록한다.

## 연동 기능

### 1. 내일 외래 환자 브리핑 노트
- 트리거: 매일 23:00
- 입력: Google Sheets의 당일 특이 환자 메모
- 출력: 다음날 첫 번째 일정에 Gemini 요약 메모 자동 첨부
- 알림: 다음날 07:30

### 2. 주간 논문 큐레이션 등록
- 매주 월요일 완료된 논문 요약 → 월요일 점심 일정에 링크 첨부

### 3. 보험 고시 HIGH 등급 알림
- 즉시 반영: HIGH 등급 고시 발행 시 당일 일정 생성
- 제목: `⚠️ 보험 고시 변경: {주요 내용 요약}`

### 4. 콘텐츠 발행 일정
- 승인된 콘텐츠 발행 시 자동으로 Calendar에 기록
- 채널별 색상 구분 (블로그/인스타/스레드)

## n8n 연동
- Google Calendar 노드 직접 사용
- OAuth2 인증 (Google Cloud Console)
