# Feature 04 — 환자 설명문 즉석 생성

## 목적
진료 후 환자에게 제공할 맞춤형 교육 자료를 10초 내 생성한다.

## 사용 방법
1. 진단명 입력
2. 환자 특성 선택 (연령대, 교육 수준)
3. 포함할 항목 체크박스 선택
4. `생성` 클릭
5. 출력 → A5 프린트 또는 QR코드로 환자 스마트폰 전송

## 사전 구성 템플릿 (10종)

| 번호 | 주제 | 핵심 항목 |
|---|---|---|
| 1 | 당뇨 초진 교육 | 혈당 목표치, 식이, 운동, 자가 모니터링 |
| 2 | 고혈압 복약 안내 | 복약 시간, 부작용, 생활습관 |
| 3 | 대장내시경 준비 | 금식 시간, 장 세척제 복용법 |
| 4 | 금연 상담 | 금단 증상, 금연 보조제 |
| 5 | 변비 식이 가이드 | 식이섬유, 수분, 운동 |
| 6 | 고지혈증 관리 | 식이 제한, 스타틴 복약 |
| 7 | 갑상선 결절 추적 | 추적 초음파 주기, 관찰 기준 |
| 8 | 위식도역류 생활요법 | 식후 눕기 금지, 식이 조절 |
| 9 | 만성 요통 관리 | 운동 방법, 자세 교정 |
| 10 | 예방접종 안내 | 접종 종류, 시기, 주의사항 |

## 다국어 지원
- 기본: 한국어
- Gemini 즉시 번역: 영어, 중국어 (외국인 환자)

## Grounding 정책 (→ grounding_sources.md 참조)

환자 설명문에 포함되는 의학적 주장은 아래 순서로 검증한다:

1. **PubMed E-utilities** (Priority 1)
   - 진단명 + 치료 키워드로 ESearch → 최신 3편 초록 수집
   - Gemini가 설명문 내용과 초록 일치 여부 확인
   - 일치 시 설명문 하단에 `✅ 근거: PubMed {PMID}` 표시 (의사 확인용)

2. **보험 고시 크롤링** (Priority 2, 처방 관련 설명문에 한함)
   - 처방약 급여 기준, 복약 횟수 제한 등 보험 관련 내용 포함 시 적용

3. **Perplexity** (Fallback)
   - PubMed 0건 AND 고시 미해당 시에만 사용
   - `⚠️ Perplexity 참고` 레이블 자동 부착

### 빠른 검증 모드 (외래 중)
외래 중 속도가 중요할 때는 grounding을 **비동기**로 실행:
설명문을 먼저 표시하고, 백그라운드에서 PubMed 확인 완료 후 레이블 업데이트.
