# Feature 02 — 감별 진단 보조

## 목적
외래 진료 중 어려운 감별 진단 케이스에서 AI를 2nd opinion으로 활용한다.

## 사용 방법
1. 대시보드 감별 진단 패널 열기
2. 증상·바이탈·주요 검사 수치 텍스트 입력
3. 초음파 스크린샷 드래그앤드롭 (선택)
4. `감별 분석` 버튼 클릭
5. Gemini API → 감별 5개 + 각 감별의 핵심 구분 포인트 출력
6. `Perplexity로 가이드라인 확인` 버튼 → 새 탭 자동 쿼리

## 근거
LLM 보조를 받은 의사의 감별 진단 정확도:
- 상위 10개 정확도: 51.7% (보조) vs 36.1% (비보조)
- 구글 검색만 했을 때보다 유의미하게 우수

## Gemini 멀티모달 활용
- 초음파 이미지 직접 업로드 가능
- Med-Gemini: 의료 이미지 벤치마크 GPT-4V 대비 +44.5%
- 복부 초음파, 갑상선 결절, 경동맥 IMT 평가 등 적용

## 활용 시나리오

| 상황 | 쿼리 패턴 |
|---|---|
| 복부 초음파 | `이 에코 패턴에서 HCC vs 혈관종 vs 전이암 감별 포인트` |
| 갑상선 결절 | `TIRADS 분류 기준으로 이 결절 평가` |
| 경동맥 초음파 | `IMT 측정치 기반 심혈관 위험도 계산` |
| 통증 외래 | `우상복부 불편감 + AST/ALT 경미한 상승 감별 5가지` |

## 주의사항
- 최종 판단은 반드시 임상의가 직접 수행
- AI는 '놓쳤을 수 있는 감별' 체크 목적으로 사용
- 출력 결과에 `⚠️ AI 보조 의견 — 임상의 판단 필수` 레이블 자동 부착
