📱 OpenManus on Galaxy Note20
DroidDesk 버전 — 초보자 완전 가이드

✅ 이 가이드는 DroidDesk를 사용합니다.
기존 Termux 가이드보다 설치 과정이 훨씬 단순합니다.
DroidDesk가 Termux + Ubuntu 설치를 자동으로 처리해 주기 때문에,
사용자는 버튼 3번 클릭으로 Ubuntu 환경을 준비할 수 있습니다.

대상 기기: Galaxy Note20 / Note20 Ultra (Snapdragon 865, ARM64, 256GB)
루팅 필요 여부: 불필요 (No Root)

DroidDesk가 뭘 해주는 건가요?

DroidDesk는 원래 복잡한 Termux 설치 과정 전체를 자동화한 오픈소스 프로젝트입니다.

단계Termux 직접 설치 어려움DroidDesk 쉬움
Termux 설치F-Droid에서 APK 찾아서 직접 설치DroidDesk APK 하나만 설치
Ubuntu 설치명령어 5줄 입력앱 안에서 버튼 클릭 1번
Ubuntu 진입매번 proot-distro login ubuntu 입력앱에서 "Launch" 버튼 클릭
VS Code, Chromium별도 설치 필요TUR repo 통해 원클릭 설치
OpenManus 세팅 이후동일 (API Key, config.toml 등)

0단계: Google API Key 발급 (무료 AI의 열쇠)

  1. 갤럭시 브라우저에서 https://aistudio.google.com/apikey 접속
  2. Google 계정으로 로그인 후 "Create API key" 파란 버튼 클릭
  3. 화면에 나타나는 AIzaSy... 로 시작하는 긴 문자열 복사
  4. 갤럭시 메모 앱에 붙여넣어 저장 (창 닫으면 다시 못 찾음)

1단계: DroidDesk 설치 (버튼 3번으로 Ubuntu 완성)

⚠️ Google Play Store에서 설치하면 안 됩니다.
DroidDesk는 Play Store에 없습니다. 아래 GitHub 링크에서 직접 받아야 합니다.
  1. 갤럭시 브라우저에서 아래 주소 접속: 
    https://github.com/orailnoor/DroidDesk/releases
  2. 최신 버전의 .apk 파일을 누르고 다운로드합니다.
  3. 다운로드된 APK 파일을 탭하여 설치합니다.
    "알 수 없는 출처" 팝업이 뜨면 → 설치 허용을 누릅니다.
  4. DroidDesk 앱을 실행합니다.
  5. 앱 내에서 "Ubuntu" 선택 → "Install" 버튼 클릭
    (Wi-Fi 연결 필수, 500MB~1GB 다운로드, 10~20분 소요)
  6. 완료되면 "Install XFCE4 Desktop" 버튼 클릭 (데스크톱 GUI 설치)
  7. "Launch Desktop" 버튼 클릭
    → 갤럭시 화면에 Linux 바탕화면이 뜨면 성공입니다!
  8. 바탕화면의 터미널 아이콘을 눌러서 검은 터미널 창을 엽니다.
    이제부터 이 터미널이 Termux 가이드의 "Ubuntu 검은 창"과 동일합니다.
💡 팁: Termux 직접 설치와의 차이
DroidDesk를 통해 열리는 터미널은 이미 Ubuntu(root@localhost) 환경입니다.
기존 Termux 가이드에서 했던 proot-distro install ubuntu, proot-distro login ubuntu 과정이 모두 생략됩니다.

2단계: 개발 도구 설치

DroidDesk 터미널 안(Ubuntu, root@localhost)에서 아래 명령어를 순서대로 입력합니다.

  1. Ubuntu 업데이트: 
    apt update && apt upgrade -y
  2. 필수 도구 설치: 
    apt install -y git curl build-essential python3 python3-pip python3-venv nodejs npm nano
  3. Python 패키지 도구(uv) 설치: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc

3단계: ARM용 Chromium 설치 (갤럭시 전용 핵심 단계)

❌ Windows 가이드와 다른 핵심 부분입니다.
갤럭시(ARM64)에서는 playwright install chromium으로 자동 설치가 되지 않습니다.
DroidDesk의 TUR(Termux User Repository)를 통해 ARM용 Chromium을 별도로 설치해야 합니다.

방법: DroidDesk 앱 내 패키지 설치 or 터미널에서 직접

터미널(Ubuntu)에서 아래 실행:

# DroidDesk 내장 TUR repo를 통해 Chromium 설치
# (Ubuntu 내부에서 Termux 레이어의 패키지를 호출하는 방식)
# 먼저 Termux 레이어로 잠깐 나갑니다
exit

이제 Termux 프롬프트(~ $)에서:

pkg install x11-repo -y
pkg install chromium -y
which chromium-browser

/data/data/com.termux/files/usr/bin/chromium-browser 경로가 나오면 성공.

다시 Ubuntu로 재진입:

proot-distro login ubuntu

OpenManus가 이 Chromium을 쓰도록 환경변수 등록:

echo 'export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/data/data/com.termux/files/usr/bin/chromium-browser' >> ~/.bashrc
source ~/.bashrc
💡 DroidDesk의 장점:
DroidDesk 앱 내부의 "Apps" 메뉴에서 Chromium을 GUI 버튼으로 설치할 수도 있습니다. 터미널이 불편하면 그쪽을 먼저 시도해 보세요.

4단계: OpenManus 설치 및 Chromium 연결

다시 Ubuntu 터미널(root@localhost)에서 진행합니다.

  1. OpenManus 다운로드: 
    cd ~
git clone https://github.com/FoundationAgents/OpenManus.git
cd OpenManus
  2. 가상환경 및 라이브러리 설치 (3~10분): 
    uv venv --python 3.12
source .venv/bin/activate
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 pip install playwright
uv pip install -r requirements.txt
  3. OpenManus 브라우저 코드에 --no-sandbox 패치 (Android ARM 필수): 
    nano app/tools/browser_use_tool.py

    Ctrl+W 로 headless 검색 → launch( 블록 안에 아래 args 추가:

    args=['--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage', '--disable-gpu']

    저장: Ctrl+O → Enter → Ctrl+X

5단계: API Key 저장 및 config.toml 작성

  1. API Key 저장 (YOUR_KEY_HERE를 실제 키로 교체): 
    mkdir -p ~/.secrets
echo 'export GEMINI_API_KEY="YOUR_KEY_HERE"' > ~/.secrets/gemini.env
echo 'source ~/.secrets/gemini.env' >> ~/.bashrc
source ~/.bashrc

    확인 (키 값이 출력되면 성공):

    echo $GEMINI_API_KEY
  2. config.toml 작성: 
    cd ~/OpenManus
cp config/config.example.toml config/config.toml
nano config/config.toml
  3. 기존 내용 모두 지우고(Ctrl+K 반복) 아래 내용 붙여넣기: 
    [llm]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[llm.vision]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[agent]
max_steps = 15

[browser]
headless = true
  4. 저장(Ctrl+O → Enter) 후 종료(Ctrl+X)

6단계: 실행 및 자동 실행 스크립트

기본 실행

cd ~/OpenManus
source .venv/bin/activate
python main.py

자동 실행 스크립트 (.sh) 만들기

DroidDesk 터미널이 아닌 Termux 레이어에서 만들어야 합니다.
Ubuntu에서 나간 뒤 (exit) 아래를 실행합니다:

nano ~/run_openmanus.sh

아래 내용 붙여넣기:

#!/data/data/com.termux/files/usr/bin/bash
echo "=================================="
echo " OpenManus + Gemma 4 실행기 (DroidDesk)"
echo "=================================="
echo "[1] 일반 모드 (main.py)"
echo "[2] MCP 모드 (run_mcp.py)"
echo ""
read -p "번호 선택: " choice

if [ "$choice" = "1" ]; then
  proot-distro login ubuntu -- bash -c "cd ~/OpenManus && source ~/.bashrc && source .venv/bin/activate && python main.py"
elif [ "$choice" = "2" ]; then
  proot-distro login ubuntu -- bash -c "cd ~/OpenManus && source ~/.bashrc && source .venv/bin/activate && python run_mcp.py -i"
else
  echo "종료"
fi

저장(Ctrl+O → Enter → Ctrl+X) 후 실행 권한 부여:

chmod +x ~/run_openmanus.sh

이후 DroidDesk의 터미널 아이콘 말고, Termux 레이어를 열어서 아래 한 줄만 입력:

~/run_openmanus.sh
💡 더 쉬운 방법:
DroidDesk 앱에서 Ubuntu 바탕화면을 열면, 터미널 앱을 바탕화면에 고정해 두고 위 스크립트를 즐겨찾기로 등록할 수 있습니다. 매번 명령어를 치지 않아도 됩니다.

7단계: MCP 연동 (GitHub, Google Drive, NAS)

DroidDesk 터미널(Ubuntu)에서 동일하게 진행합니다.

cd ~/OpenManus/config
nano mcp.json

아래 내용 붙여넣기 (사용하지 않을 서비스 블록은 삭제):

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "YOUR_GITHUB_PAT_여기에_입력"
      }
    },
    "gdrive": {
      "command": "npx",
      "args": ["-y", "@isaacphi/mcp-gdrive"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/root/.secrets/gdrive.json"
      }
    }
  }
}

NAS 연결 (갤럭시 전용 — sshfs 사용)

Android에서는 Windows Z드라이브 방식이 불가능합니다. ipTIME NAS에 SSH가 켜져 있다면:

apt install -y sshfs
mkdir -p ~/nas
sshfs admin@192.168.0.2:/myfolder ~/nas -p 22

mcp.json에 NAS 추가:

"nas": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/root/nas"]
}

MCP 모드 실행:

cd ~/OpenManus
source .venv/bin/activate
python run_mcp.py -i
