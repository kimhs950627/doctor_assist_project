📱 OpenManus on Galaxy Note20
Termux + proot-distro(Ubuntu) 초보자 완전 가이드

대상 기기: Galaxy Note20 / Note20 Ultra (Snapdragon 865, ARM64, 256GB)
Android 버전: 12 이상
루팅 필요 여부: 불필요 (No Root)
이 가이드는 기존 Windows WSL2 튜토리얼을 갤럭시 환경에 맞게 수정한 버전입니다.

Windows vs 갤럭시폰: 핵심 차이점

항목Windows (WSL2)Galaxy Note20 (Termux)
Linux 환경WSL2가 자동으로 제공Termux + proot-distro로 직접 설치
Chromium (브라우저 자동화)playwright install chromium 자동 설치자동 불가. Termux용 Chromium을 따로 깔고 경로 수동 연결
배치파일(.bat)더블클릭 가능불가. 대신 쉘 스크립트(.sh)로 대체
Python 3.12uv로 설치Termux 기본 패키지로 지원 (pkg install python)
NAS 마운트Z: 드라이브 → WSL /mnt/zsshfs 또는 Termux FTP 클라이언트 사용
키보드노트북 키보드Termux 앱 자체 하단 키보드 (Ctrl/Tab/화살표 포함)

0단계: 준비

Termux 설치 (Google Play 버전은 사용하지 말 것!)

⚠️ 중요: Google Play Store에 있는 Termux는 오래된 버전이라 오류가 납니다.
반드시 아래 F-Droid 경로에서 내려받아야 합니다.
  1. 갤럭시 브라우저에서 https://f-droid.org/packages/com.termux 접속
  2. Download APK 버튼 클릭해서 앱 설치
  3. 안드로이드 보안 팝업에서 "이 출처의 설치 허용" 을 눌러 설치를 완료합니다.
  4. Termux를 실행하면 검은 터미널 화면이 열립니다. 이것이 곧 Linux 환경입니다.
Termux 화면에서 긴 명령어를 편하게 입력하려면:
화면을 두 손가락으로 옆으로 스와이프하면 단축키 바(Ctrl, Alt, 화살표 키 등)가 나타납니다.

1단계: Termux 초기 세팅

Termux를 열고 아래 명령어를 한 줄씩 입력합니다.
긴 텍스트를 직접 치기 힘들면, 다른 폰/PC에서 이 페이지를 열고 복사 → 갤럭시에서 긴 터치(붙여넣기) 합니다.

  1. 패키지 업데이트: 
    pkg update && pkg upgrade -y
  2. 스토리지 권한 허용 (파일 접근에 필요): 
    termux-setup-storage
    "저장소 권한 허용" 팝업이 뜨면 허용을 누릅니다.
  3. proot-distro 설치 (갤럭시 안에 Ubuntu를 설치하는 도구): 
    pkg install proot-distro -y
  4. Ubuntu 설치 (300~500MB 소요, Wi-Fi 연결 필수): 
    proot-distro install ubuntu
  5. Ubuntu 환경으로 진입: 
    proot-distro login ubuntu
    프롬프트가 root@localhost:~# 로 바뀌면 Ubuntu 안에 들어온 것입니다.

2단계: Ubuntu 안에서 개발 도구 설치

이제부터 모든 명령어는 Ubuntu 안(root@localhost)에서 입력합니다.

  1. Ubuntu 패키지 업데이트: 
    apt update && apt upgrade -y
  2. 필수 도구 설치: 
    apt install -y git curl build-essential python3 python3-pip python3-venv nodejs npm nano
  3. 파이썬 패키지 도구 uv 설치: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc
❌ 여기서 Windows와 다른 점:
기존 가이드에서 했던 sudo apt install libglib2.0-0 ... 브라우저 의존성 라이브러리 설치는 여기서는 불필요합니다.
대신 Termux용 Chromium을 Termux 레이어(Ubuntu 바깥)에서 따로 설치합니다. (아래 4단계 참조)

3단계: OpenManus 설치 (Ubuntu 안에서)

  1. OpenManus 다운로드: 
    cd ~
git clone https://github.com/FoundationAgents/OpenManus.git
cd OpenManus
  2. 가상환경 생성 및 라이브러리 설치: 
    uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt
  3. Playwright 브라우저 자동 다운로드는 건너뜁니다: 
    PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 pip install playwright

4단계: 갤럭시 전용 - Chromium 연결 (핵심)

Windows 가이드와의 핵심 차이점입니다.
ARM 기반 Android에서는 Playwright가 기본적으로 Chromium을 다운로드할 수 없습니다.
Termux에서 제공하는 ARM용 Chromium을 설치하고, OpenManus에게 그 경로를 알려줘야 합니다.

Step 1: Termux 레이어로 빠져나가서 Chromium 설치

Ubuntu를 잠깐 나갑니다:

exit

이제 Termux 프롬프트(~ $)에서 입력:

# X11 저장소 활성화 (ARM용 Chromium 제공)
pkg install x11-repo -y
pkg install chromium -y

설치된 Chromium 경로 확인:

which chromium-browser

/data/data/com.termux/files/usr/bin/chromium-browser 라고 나오면 성공입니다.

다시 Ubuntu 환경으로 들어갑니다:

proot-distro login ubuntu

Step 2: OpenManus가 이 Chromium을 쓰도록 환경변수 등록

cd ~/OpenManus
echo 'export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/data/data/com.termux/files/usr/bin/chromium-browser' >> ~/.bashrc
source ~/.bashrc

Step 3: OpenManus BrowserTool 설정에서 --no-sandbox 강제 적용

Android/ARM 환경에서는 Chromium이 샌드박스 없이 실행되어야 합니다.
아래 명령으로 OpenManus 코드에 패치를 적용합니다:

cd ~/OpenManus
grep -rn "chromium.launch" app/ --include="*.py"

위 명령으로 출력된 파일을 열고, chromium.launch( 부분을 아래처럼 수정합니다:

nano app/tools/browser_use_tool.py

Ctrl+W 로 headless 검색 후, launch 블록에 아래 args 추가:

args=['--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage', '--disable-gpu']

저장: Ctrl+O → Enter → Ctrl+X

5단계: API Key 저장 및 config.toml 작성

이 단계는 Windows 가이드와 동일합니다. Ubuntu 안(root@localhost)에서 입력합니다.

  1. API Key 저장 (YOUR_KEY_HERE를 실제 키로 교체): 
    mkdir -p ~/.secrets
echo 'export GEMINI_API_KEY="YOUR_KEY_HERE"' > ~/.secrets/gemini.env
echo 'source ~/.secrets/gemini.env' >> ~/.bashrc
source ~/.bashrc
  2. config.toml 작성: 
    cd ~/OpenManus
cp config/config.example.toml config/config.toml
nano config/config.toml
  3. 기존 내용 모두 지우고(Ctrl+K 반복) 아래 내용 붙여넣기: 
    [llm]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[llm.vision]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[agent]
max_steps = 15

[browser]
headless = true
  4. 저장(Ctrl+O → Enter) 후 종료(Ctrl+X)

6단계: 실행 및 자동 실행 스크립트

실행 방법

cd ~/OpenManus
source .venv/bin/activate
python main.py

갤럭시용 자동 실행 스크립트 만들기 (Windows .bat 대신 .sh)

Windows에서 .bat 파일을 만든 것처럼, 갤럭시에서는 쉘 스크립트(.sh)로 한 번에 실행하는 메뉴를 만들 수 있습니다.
이 스크립트는 Termux 레이어에서 만들고 실행합니다. (exit으로 Ubuntu 나간 뒤)

exit   # Ubuntu에서 나가기 (Termux 레이어로)
nano ~/run_openmanus.sh

아래 내용 붙여넣기:

#!/data/data/com.termux/files/usr/bin/bash
echo "=================================="
echo " OpenManus + Gemma 4 실행기 (갤럭시)"
echo "=================================="
echo "[1] 일반 모드 (main.py)"
echo "[2] MCP 모드 (run_mcp.py)"
echo ""
read -p "번호 선택: " choice

if [ "$choice" = "1" ]; then
  proot-distro login ubuntu -- bash -c "cd ~/OpenManus && source ~/.bashrc && source .venv/bin/activate && python main.py"
elif [ "$choice" = "2" ]; then
  proot-distro login ubuntu -- bash -c "cd ~/OpenManus && source ~/.bashrc && source .venv/bin/activate && python run_mcp.py -i"
else
  echo "종료"
fi

저장(Ctrl+O → Enter → Ctrl+X) 후 실행 권한 부여:

chmod +x ~/run_openmanus.sh

이제 Termux를 열 때마다 아래 한 줄만 입력하면 메뉴가 뜹니다:

~/run_openmanus.sh

7단계: MCP 연동 (GitHub / NAS)

Windows 가이드와 동일하게 config/mcp.json을 작성합니다. Ubuntu 안에서 진행합니다.

proot-distro login ubuntu
cd ~/OpenManus/config
nano mcp.json

내용 작성 (Windows 가이드의 mcp.json과 동일한 방식):

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx..."
      }
    }
  }
}

NAS 연결 (갤럭시 전용)

Windows처럼 Z: 드라이브를 마운트할 수 없으므로, sshfs를 사용해 NAS를 마운트합니다.
ipTIME은 기본적으로 FTP 외에 SSH도 설정 가능합니다. SSH가 켜져 있다면:

apt install -y sshfs
mkdir -p ~/nas
sshfs admin@192.168.0.2:/myfolder ~/nas -p 22

그 뒤 mcp.json에 추가:

"nas": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/root/nas"]
}
