GUI-FIRST · NO LOCAL LLM

Galaxy Note20에서
OpenManus 시작하기

DroidDesk의 버튼과 Ubuntu desktop을 먼저 이용하고, terminal 명령은 꼭 필요한 3개 블록으로 줄인 installation guide다. LLM 추론은 휴대폰이 아닌 Gemini API에서 수행한다.

이 가이드의 목표

Galaxy Note20을 Gemini API 기반 OpenManus orchestration + lightweight browser worker로 시험한다. Local Ollama/Gemma model download나 GPU inference는 하지 않는다.

시작 전 확인 · DroidDesk GUI 설치 · 필수 terminal 3단계 · Smoke test · 문제 해결

시작 전 확인

  • Galaxy Note20 또는 Note20 Ultra, 안정적인 Wi-Fi, 충전기 연결
  • Internal storage 여유 8 GB 이상 권장 (Ubuntu desktop + browser cache 포함)
  • Google Gemini API key: 휴대폰에서 local model을 다운로드하지 않는다.
  • GitHub account: OpenManus upstream clone에 사용
PHI 금지: 이 단계의 OpenManus test에는 환자식별정보, EMR 화면, 실제 patient data를 넣지 않는다. 예시는 public documentation URL이나 비임상 dummy prompt만 사용한다.

1–3. DroidDesk에서 GUI로 Linux Desktop 만들기

1

DroidDesk APK 설치

Android Chrome에서 DroidDesk 공식 GitHub Release를 열고 최신 APK를 내려받는다. Android가 install 차단을 표시하면 Chrome에 대해 Allow from this source를 허용한 뒤 설치한다.

Browser → DroidDesk GitHub Releases → APK download → Install

DroidDesk는 Termux, Termux X11, TUR, PRoot를 이용해 root 없이 Android 위 Linux desktop을 구성한다.

2

Ubuntu 설치 버튼 누르기

DroidDesk를 열고 Ubuntu 항목을 고른다. 처음에는 Install을 누른다. 설치 중에는 앱을 닫지 말고 Wi-Fi와 충전을 유지한다.

DroidDesk home → Ubuntu → Install → completion message 확인
3

Desktop을 실행하고 Terminal 열기

설치가 끝나면 Launch Desktop 또는 Start Desktop을 선택한다. XFCE 화면이 열리면 application menu에서 Terminal을 실행한다. 이후 terminal은 아래 3개 code block을 한 번씩 붙여넣는 용도로만 쓴다.

여기까지가 GUI 영역이다. Ubuntu 설치, GUI desktop start, browser launch는 DroidDesk 화면에서 수행한다.

4–6. 필요한 Terminal 명령은 3번

4

Block A — OpenManus 설치

Ubuntu Desktop의 Terminal에서 아래 전체 block을 복사해 붙여넣고 Enter를 누른다. 완료될 때까지 기다린다.

sudo apt update && sudo apt install -y git curl python3 python3-venv python3-pip
mkdir -p ~/services && cd ~/services
git clone https://github.com/FoundationAgents/OpenManus.git
cd OpenManus
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt

완료 확인: 마지막 줄에 error 없이 prompt가 다시 나타난다.

5

Block B — Gemini API secret과 config 만들기

아래 block에서 PASTE_YOUR_GEMINI_KEY_HERE만 실제 key로 바꾼다. key를 GitHub, screenshot, Telegram message에 올리지 않는다.

cd ~/services/OpenManus
source .venv/bin/activate
mkdir -p ~/.secrets config
printf 'export GEMINI_API_KEY="PASTE_YOUR_GEMINI_KEY_HERE"\n' > ~/.secrets/gemini.env
chmod 600 ~/.secrets/gemini.env
source ~/.secrets/gemini.env
cp config/config.example.toml config/config.toml
nano config/config.toml

nano editor 화면에서 OpenManus upstream example의 provider/model field를 현재 지원되는 Gemini API configuration에 맞춘다. API key literal을 config file에 중복 저장하지 말고 environment variable reference가 지원되는지 먼저 확인한다.

중요: OpenManus version마다 Gemini direct provider support와 config key가 다를 수 있다. 먼저 config/config.example.toml의 주석과 installed package documentation을 확인한다. direct Gemini가 안 되면 이 단계에서 멈추고 config issue로 기록한다. Ollama 설치로 돌아가지 않는다.
6

Block C — Browser와 Python smoke 준비

DroidDesk desktop에서 Chromium 또는 Firefox를 먼저 클릭해 정상적으로 열리는지 확인한다. 그 뒤 terminal에 아래 block을 실행한다. 이 명령은 Playwright가 browser binary를 준비할 수 있는지 확인한다.

cd ~/services/OpenManus
source .venv/bin/activate
python -m playwright install chromium
python -c "import platform; print('arch:', platform.machine())"
python -c "import playwright; print('playwright: import OK')"
ARM64 warning: playwright install chromium가 실패할 수 있다. 이는 Gemini API 문제가 아니라 Android/ARM64 browser binary issue다. 아래 troubleshooting대로 log를 남긴 뒤 browser-less test부터 진행한다.

한 번에 복잡한 medical research를 시키지 않는다. 각 단계가 성공해야 다음 단계로 간다.

python main.py 2>&1 | tee ~/services/OpenManus/workspace/smoke/OM-00_note20.log

API key, token, cookie는 log에 남기지 않는다. error가 나면 error message와 device/Python/OpenManus commit만 기록한다.

문제 해결

1. DroidDesk install이 멈춘다

Wi-Fi, storage, charging을 확인한다. app을 force-close하지 말고, storage가 8 GB 미만이면 Android data/cache를 정리한 뒤 재시도한다.

2. sudo가 없다

PRoot distro image에 따라 root shell로 시작될 수 있다. 이때 command에서 sudo만 빼고 실행한다.

3. python -m playwright install chromium 실패

가장 흔한 ARM64 issue다. OpenManus 전체가 실패한 것으로 판단하지 말고 OM-00 API-only test를 먼저 한다. 이후 Termux-compatible Chromium binary와 explicit executable path 방식은 별도 test document로 다룬다.

4. Gemini configuration error

현재 OpenManus clone의 config/config.example.toml과 README를 기준으로 provider support를 확인한다. config file에 key를 hard-code한 경우 즉시 key rotate를 고려한다.

5. Phone이 자꾸 멈추거나 app이 꺼진다

Battery optimization에서 DroidDesk/Termux 관련 app을 unrestricted으로 두고, charging 상태에서 1 job만 sequential 실행한다. 긴 browser job은 laptop worker로 보낸다.

운영 원칙

  • No local inference: Ollama, local Gemma, model weight download를 이 guide 범위에 넣지 않는다.
  • One job at a time: Note20에서는 concurrent browser job을 실행하지 않는다.
  • Evidence first: research output은 JSON artifact로 남기고, Gemini editorial은 저장된 evidence를 기반으로 만든다.
  • PHI isolation: initial test와 public research worker에는 patient-identifiable data를 넣지 않는다.
  • Fallback: browser task가 불안정하면 Note20은 control node로 유지하고 laptop을 browser worker로 쓴다.
