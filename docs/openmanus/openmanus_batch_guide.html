OpenManus + Gemma 4
초보자용 자동 실행 가이드

이 가이드는 터미널(검은 창)에 명령어를 매번 치기 힘든 분들을 위해,
바탕화면에서 더블클릭만으로 실행되는 배치(Batch) 파일을 만드는 방법을 소개합니다.

3부: 바탕화면 "더블클릭 자동 실행기" 만들기

매번 wsl 켜고 cd ~/OpenManus 치고 source .venv... 하는 과정을 단 한 번의 클릭으로 자동화합니다. 특히 NAS 마운트도 비밀번호 없이 자동으로 처리하게 만들 수 있습니다.

1. 메모장 열기

Windows 시작 버튼을 누르고 메모장을 검색해서 엽니다.

2. 아래 코드 복사/붙여넣기

아래 회색 박스 안의 코드를 모두 복사해서 메모장에 붙여넣습니다.

@echo off
chcp 65001 >nul
title OpenManus AI 실행기

echo ===================================================
echo             OpenManus + Gemma 4 실행기
echo ===================================================
echo.
echo [1] 일반 모드로 실행 (단순 대화 / main.py)
echo [2] 외부 연동(MCP) 모드로 실행 (run_mcp.py)
echo [3] NAS 드라이브(Z:) 마운트 후 MCP 모드 실행
echo [4] 종료
echo.
set /p choice="원하는 번호를 입력하고 Enter를 누르세요: "

if "%choice%"=="1" (
    echo.
    echo 일반 모드를 실행합니다...
    wsl -d Ubuntu-24.04 -- bash -ic "cd ~/OpenManus && source .venv/bin/activate && python main.py"
) else if "%choice%"=="2" (
    echo.
    echo MCP 모드를 실행합니다...
    wsl -d Ubuntu-24.04 -- bash -ic "cd ~/OpenManus && source .venv/bin/activate && python run_mcp.py -i"
) else if "%choice%"=="3" (
    echo.
    echo NAS(Z: 드라이브)를 WSL에 연결합니다...
    REM root 권한으로 마운트하여 비밀번호 입력을 생략합니다.
    wsl -d Ubuntu-24.04 -u root -- mkdir -p /mnt/z
    wsl -d Ubuntu-24.04 -u root -- mount -t drvfs Z: /mnt/z
    echo 연결 완료! MCP 모드를 실행합니다...
    wsl -d Ubuntu-24.04 -- bash -ic "cd ~/OpenManus && source .venv/bin/activate && python run_mcp.py -i"
) else (
    exit
)
pause

3. 바탕화면에 .bat 파일로 저장하기

  1. 메모장 메뉴에서 파일 → 다른 이름으로 저장을 클릭합니다.
  2. 저장 위치를 바탕화면으로 선택합니다.
  3. 파일 형식을 '텍스트 문서(*.txt)'에서 '모든 파일(*.*)'로 변경합니다.
  4. 파일 이름을 OpenManus실행기.bat 로 입력합니다. (.bat 확장자가 제일 중요합니다)
  5. 인코딩이 UTF-8로 되어 있는지 확인하고 저장 버튼을 누릅니다.

4. 사용하기

이제 바탕화면에 톱니바퀴 모양(또는 빈 창 모양)의 OpenManus실행기 파일이 생겼습니다.
더블클릭하면 1, 2, 3번을 선택할 수 있는 대화형 메뉴가 뜨며, 번호만 누르면 AI가 즉시 실행됩니다.

💡 특별한 팁 (NAS 연동):
3번을 선택하면 wsl -u root 명령을 통해 비밀번호 입력 과정 없이 백그라운드에서 Z: 드라이브를 강제로 마운트한 뒤 OpenManus를 띄워줍니다! (사전에 Windows 탐색기에서 Z: 드라이브가 연결되어 있어야 합니다.)
