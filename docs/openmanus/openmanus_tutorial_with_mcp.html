OpenManus + Gemma 4
기본 세팅 및 외부 저장소(MCP) 연동 가이드

이 가이드는 완전 초보자를 위해 작성되었습니다.
1부는 AI 에이전트를 내 컴퓨터에 설치하는 기본 과정,
2부는 내 깃허브, 구글 드라이브, 원드라이브, 개인 NAS를 AI와 연결하는 심화 과정입니다.

1부: 기본 설치 및 환경 세팅

0단계: Google API Key 발급받기 (무료 AI의 열쇠)

  1. 크롬이나 엣지 브라우저에서 https://aistudio.google.com/apikey 에 접속합니다.
  2. Google 계정으로 로그인 후 "Create API key" 파란 버튼을 클릭합니다.
  3. 화면에 나타나는 AIzaSy... 로 시작하는 긴 문자열을 복사합니다.
  4. 메모장에 붙여넣어 안전하게 저장해 둡니다.

1단계: PowerShell 열기 및 Ubuntu 설치

  1. 화면 맨 아래 시작 버튼(Windows 로고) 우클릭 → "터미널(관리자)" 클릭.
  2. 파란색(또는 검은색) 창이 열리면 아래 명령어를 복사해서 붙여넣고 Enter: 
    wsl --install -d Ubuntu-24.04
  3. 설치 완료 후 컴퓨터를 재부팅합니다.
  4. 재부팅 후 열리는 검은 창에서 영어 소문자로 아이디(예: kim)를 입력하고 Enter.
  5. 비밀번호를 두 번 입력합니다 (입력 시 화면에 아무것도 안 보이지만 정상입니다).

2단계: 필수 도구 설치 (명령어 복사/붙여넣기)

초록색 글씨의 프롬프트가 보이면 아래 명령어를 한 블록씩 차례대로 복사/붙여넣기 하고 Enter를 누릅니다.

  1. 운영체제 업데이트 (비밀번호 요구 시 입력): 
    sudo apt update && sudo apt upgrade -y
  2. 기본 도구 및 Node.js 설치 (MCP 연동에 필수!): 
    sudo apt install -y git curl build-essential nodejs npm
  3. 파이썬 패키지 도구(uv) 설치: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc
  4. 브라우저 자동화 라이브러리 설치: 
    sudo apt install -y libglib2.0-0 libnss3 libnspr4 libdbus-1-3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxcb1 libxkbcommon0 libx11-6 libxcomposite1 libxdamage1 libxext6 libxfixes3 libxrandr2 libgbm1 libpango-1.0-0 libcairo2 libasound2t64

3단계: OpenManus 다운로드 및 세팅

cd ~
git clone https://github.com/FoundationAgents/OpenManus.git
cd OpenManus
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt
playwright install chromium

4단계: API Key 저장 및 config.toml 작성

  1. 키를 컴퓨터에 저장 (YOUR_KEY_HERE 부분을 내 키로 변경): 
    mkdir -p ~/.secrets
echo 'export GEMINI_API_KEY="YOUR_KEY_HERE"' > ~/.secrets/gemini.env
echo 'source ~/.secrets/gemini.env' >> ~/.bashrc
source ~/.bashrc
  2. 설정 파일 백지화 후 열기: 
    cp config/config.example.toml config/config.toml
nano config/config.toml
  3. 기존 내용 전부 지우고(Ctrl+K 반복), 아래 내용 붙여넣기: 
    [llm]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[llm.vision]
model = "gemma-4-31b-it"
base_url = "https://generativelanguage.googleapis.com/v1beta/openai/"
api_key = "${GEMINI_API_KEY}"
max_tokens = 4096
temperature = 0.0

[agent]
max_steps = 15

[browser]
headless = true
  4. 저장(Ctrl+O → Enter) 후 종료(Ctrl+X)

2부: 심화 - 외부 저장소 연결 (MCP 세팅)

MCP(Model Context Protocol)란?
AI가 깃허브, 구글드라이브 같은 외부 서비스의 파일을 직접 읽고 쓸 수 있게 연결해주는 다리입니다.
아래 설정 파일(mcp.json) 하나만 작성하면 모든 연결이 끝납니다.

사전 준비: 각각의 서비스 권한 얻기

① GitHub

GitHub 계정 세팅에서 Personal Access Token (PAT)을 발급받아 메모장에 둡니다. (예: ghp_xxx...)

② 개인 NAS (ipTIME FTP 우회법 - 가장 추천)

복잡한 FTP 플러그인 대신 윈도우의 '네트워크 드라이브'를 이용하는 것이 압도적으로 편하고 안전합니다.

  1. 윈도우 탐색기 열기 → "내 PC" 우클릭 → 네트워크 드라이브 연결 클릭
  2. 드라이브 문자를 Z: 로 선택
  3. 폴더 항목에 NAS 주소 입력 (예: \192.168.0.2\myfolder) 후 아이디/비밀번호 입력
  4. Ubuntu 검은 창을 열고, Windows의 Z 드라이브를 Ubuntu에 연결하는 명령어 입력: 
    sudo mkdir -p /mnt/z
sudo mount -t drvfs Z: /mnt/z
  5. 이제 AI는 /mnt/z 경로를 통해 NAS 파일에 자유롭게 접근할 수 있습니다.

③ Google Drive & OneDrive (OAuth 인증 파일)

이 두 서비스는 보안이 강력하여 클라우드 개발자 콘솔에서 앱을 만들고 인증 JSON 파일이나 Client ID를 발급받아야 합니다.
- Google Drive: Google Cloud Console에서 '데스크톱 앱'용 OAuth JSON 파일 다운로드 후 Ubuntu의 ~/.secrets/gdrive.json으로 저장.
- OneDrive: Azure Portal에서 앱 등록 후 Client ID 복사.

최종 연동: mcp.json 파일 작성하기

OpenManus에게 연결할 도구 목록을 알려주는 단계입니다.

  1. 설정 파일 만들기: 
    cd ~/OpenManus/config
nano mcp.json
  2. 아래 코드를 복사해서 붙여넣습니다. (사용하지 않을 서비스는 해당 블록을 지우면 됩니다.)
    ※ YOUR_GITHUB_PAT 등 본인의 키로 변경하세요. 
    {
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "YOUR_GITHUB_PAT_여기에_입력"
      }
    },
    "nas": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/mnt/z"]
    },
    "gdrive": {
      "command": "npx",
      "args": ["-y", "@isaacphi/mcp-gdrive"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/home/kim/.secrets/gdrive.json"
      }
    },
    "onedrive": {
      "command": "npx",
      "args": ["-y", "kennyr859-onedrive-mcp"],
      "env": {
        "MICROSOFT_CLIENT_ID": "YOUR_AZURE_CLIENT_ID_여기에_입력",
        "MICROSOFT_TENANT_ID": "common"
      }
    }
  }
}
  3. 저장(Ctrl+O → Enter) 후 종료(Ctrl+X)

cd ~/OpenManus
source .venv/bin/activate
python run_mcp.py -i

이제 프롬프트 창에 이렇게 명령할 수 있습니다!

  • 💬 "내 깃허브의 doctor-assist 레포지토리에 있는 최근 커밋 내역을 알려줘"
  • 💬 "NAS(로컬 파일시스템 /mnt/z)에 있는 '의학통계.xlsx' 파일을 읽고 내용을 요약해줘"
  • 💬 "내 구글 드라이브에서 '2026_초음파_가이드.pdf'를 검색해서 찾아줘"
⚠️ 무료 API(Gemma 4) 사용 시 주의사항:
GitHub이나 드라이브의 "전체 구조"를 한 번에 읽어오라고 하면, 요청이 폭주하여 제한(429 에러)에 걸리거나 토큰 한도(256K)를 초과합니다.
"NAS의 특정 폴더 안에 있는 파일 5개만 목록을 보여줘" 처럼 구체적이고 작게 지시하는 것이 좋습니다.
